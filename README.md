# ナディーショーダナ（片鼻呼吸法）

ナディーショーダナを視覚的にガイドする PWA です。スマホのホーム画面に追加すると、オフラインでも単体アプリとして起動します。

## 画面の読み方

セッション画面は 3 本のバーが ∩ 字に並びます。

- **左右の縦バー** … 吸う / 吐く。常に上端を固定して高さが増減します。**減る＝吸う、増える＝吐く**
- **上辺の横バー** … 止める。息が入ってきた側から減っていきます

1 ラウンドは 6 フェーズです。

1. 左から吸う
2. 止める（両鼻）
3. 右から吐く
4. 右から吸う
5. 止める（両鼻）
6. 左から吐く

バーの分割数は秒数と一致します（止める 8 秒なら 8 分割）。色の境界はマス内を連続的に動き、1 秒ごとに目盛り線を通過します。1 マスが細かくなりすぎる場合のみ、目盛りなしの連続バーに切り替わります。

## プリセット

| プリセット | 吸う / 止める / 吐く | 1ラウンド | 初期ラウンド数 | 所要時間 |
| --- | --- | --- | --- | --- |
| 4-8-8 | 4 / 8 / 8 秒 | 40 秒 | 4 | 2 分 40 秒 |
| 6-12-12 | 6 / 12 / 12 秒 | 60 秒 | 3 | 3 分 00 秒 |
| 4-16-8 | 4 / 16 / 8 秒 | 56 秒 | 3 | 2 分 48 秒 |
| カスタム | 自由 | — | 自由 | — |

ラウンド数は 2 / 4 / 6 / 10 から選べ、プリセットごとに最終使用値を記憶します。初期値は固定値ではなく出発点です。

## 準備シーケンス

開始ボタンを押してから呼吸が始まるまでの誘導です。スマホを置き、姿勢を整え、目を閉じるための時間を取ります。

| # | ステップ | 秒数 | 目盛り |
| --- | --- | --- | --- |
| 1 | 姿勢を整える | ホーム画面のピッカーで変更（既定 5 秒） | なし |
| 2 | 両鼻で吸う | 3 秒 | 3 分割 |
| 3 | 両鼻で吐く | 6 秒 | 6 分割 |
| 4 | 間 | 1 秒 | なし |

吸う : 吐く = 1 : 2。副交感神経が優位になる比率です。導入呼吸（2〜4）は固定で、ピッカーが変えるのは姿勢ステップのみです。

準備中は両鼻を使うため **左右のバーが同時に動き、∩ 全体が 1 色** になります。本編の片鼻呼吸では片側ずつ動き 3 色を使うため、見た目で取り違えが起きません。

画面をタップすると準備を飛ばして即座に始まります。

## 設定

### 表示設定

| 項目 | 選べるもの |
| --- | --- |
| 言語 | 日本語 / English |
| テーマ | ダーク / ライト |
| 文字の大きさ | 小 / 中 / 大 |
| バーの太さ | 細い / 普通 / 太い |

初回起動時は **2 ステップの設定画面** から始まります。

1. **表示** … 言語・テーマ・文字の大きさ・バーの太さ（言語は端末の設定から推定した値が初期選択）
2. **お知らせのしかた** … 音・ティック・振動・音声ガイド・画面を消さない

どちらもあとから「設定」でいつでも変更できます。

### システムを更新

設定の一番下にあります。Service Worker がキャッシュを持つ都合で、通常は新しい版が反映されるまで「次に 2 回起動する」必要があります。この項目を押すと、サーバー上の版番号をその場で確認し、新しければキャッシュを破棄して即座に読み直します。

- 最新であれば「最新版です」と表示されるだけで、何も起きません
- オフライン時は確認できない旨を表示します
- 更新時に実施記録や設定が消えることはありません（端末内の保存領域は触りません）

リリースのたびに `index.html` 冒頭の `APP_VERSION` を上げてください。この値が比較に使われます。

### 通知設定

- 音（チャイム）／呼吸音／秒ごとのティック
- バイブレーション
- 音声ガイド（言語に追従）
- 画面を消さない（Wake Lock）／バックグラウンド継続

## 音について

音はすべて Web Audio で合成しています。音声ファイルを持たないので容量が増えず、オフラインでも確実に鳴ります。

### チャイム

鐘の音が鐘らしく聞こえるのは、倍音が整数倍ではなく **非整数比** で並ぶためです。サイン波 1 本では出ないので、ハム・プライム・三度・五度などの部分音を重ね、高い部分音ほど速く減衰させています。撞木が当たる瞬間の音も短いノイズで加えています。

基音はフェーズごとに変えています。

| フェーズ | 音 | ねらい |
| --- | --- | --- |
| 吸う | C5 | 明るく、吸気を促す |
| 止める | G4 | 控えめ。静止を妨げない |
| 吐く | F4 | 最も低く、収まる感じ |

3 音は互いに協和するため、連続して鳴っても濁りません。

### 呼吸音

息そのものに近い帯域ノイズです。吸うときは中心周波数が上がりながら膨らみ、吐くときは下がりながら減衰します。音階を持たないのでチャイムと喧嘩しません。一時停止して再開した場合は、残り時間に合わせて鳴らし直します。

### 音声ガイド

`audio/ja/` と `audio/en/` に合成済みの音声を同梱しています（計 16 ファイル・約 131 KB）。ファイルが読めない環境では自動的に端末の読み上げ機能に切り替わるため、一部が欠けても動作します。

| ファイル名 | 日本語 | English |
| --- | --- | --- |
| `inhale-left` | 左から吸って | Inhale through the left |
| `inhale-right` | 右から吸って | Inhale through the right |
| `hold` | 止めて | Hold |
| `exhale-left` | 左から吐いて | Exhale through the left |
| `exhale-right` | 右から吐いて | Exhale through the right |
| `prep-inhale` | 両鼻で、大きく吸って | Breathe in deeply through both nostrils |
| `prep-exhale` | ゆっくり吐いて | Breathe out slowly |
| `prep-start` | 左から | From the left |

`prep-start` だけ画面表示（「左の鼻から始めます」）より短い文言です。このステップは 1 秒しかなく、全文を読むと次のフェーズに食い込んで途中で切れるためです。音声は文字より簡潔なほうが自然なので、表示と読み上げを別に持っています。

### 音声の作り直し

`tools/` に生成スクリプトがあります。Windows の音声合成（SAPI）と ffmpeg を使います。

```
powershell -NoProfile -ExecutionPolicy Bypass -File tools/gen-voice.ps1
```

文言を変えるときは `tools/voice-phrases.json` を編集してから実行してください。生成された WAV を ffmpeg で前後の無音除去・音量正規化（-18 LUFS）し、24 kHz モノラル 56 kbps の MP3 に変換したものが `audio/` の中身です。

`gen-voice.ps1` は **ASCII のみで記述する** 必要があります。Windows PowerShell 5.1 は BOM の無いスクリプトを ANSI として読むため、コメントであっても非 ASCII 文字を含めると構文解析が壊れます。読み上げる文言を JSON 側に分離しているのはこのためです。

各音声は、対応するフェーズの最短長より短くなければなりません（例：`prep-inhale` は準備の吸気 3 秒以内）。超えると次の案内に切られます。

実施記録と連続日数は端末内（localStorage）にのみ保存され、外部には送信されません。

## カラー方針

2 テーマで同じ意味づけを保ちます。

| 色 | 意味 |
| --- | --- |
| ティール | 操作できる / 今アクティブ（開始ボタン、選択中、ON のトグル、主ボタン） |
| オレンジ | 継続記録（ストリーク） |
| ニュートラル | 上記以外すべて |
| ティール / バイオレット / オレンジ | 呼吸フェーズ（吸う / 止める / 吐く）。呼吸ビジュアル内部でのみ使用 |

ライトテーマはダークと同じ色相のまま明度だけを落としています。淡い色は白地で沈むためで、文字と背景の組み合わせはすべて WCAG AA（小さい文字 4.5:1）を満たす値を実測で選定しています。

なお完了画面のチェックマークだけは、押せない要素でありながら達成感の演出を優先してティールを使っています。これは意図的な唯一の例外です。

## 動作環境

PWA としての機能（ホーム画面への追加、オフライン起動、画面ロック抑止）は **HTTPS 配信時のみ** 有効です。

## セキュリティとプライバシー

### 設計上の前提

- **外部通信を一切行いません。** `fetch` / `XMLHttpRequest` / WebSocket / ビーコンのいずれも使用していません
- **外部リソースを読み込みません。** CDN・外部フォント・解析タグはなく、依存ライブラリはゼロです
- **`eval` と動的コード生成を使用していません**
- 実施記録・連続日数・設定はすべて端末内の localStorage にのみ保存されます。サーバーに送信されることはありません

### 実装している対策

| 対策 | 内容 |
| --- | --- |
| Content Security Policy | `default-src 'self'` を基点に、外部からの読み込みと外部への送信を遮断。`object-src` `base-uri` `form-action` は `'none'` |
| 保存データの検証 | localStorage の内容は信頼せず、既知のキーのみを型と範囲を検証して取り込む。未知のキーは取り込まない |
| 出力エスケープ | 文字列を HTML として挿入する箇所はすべてエスケープを通す |
| 権限の最小化 | 要求する権限は画面ロック抑止のみ。位置情報・カメラ・マイク・通知権限は要求しません |

### 既知の制限

クリックジャッキング対策の `frame-ancestors` は HTTP ヘッダでしか機能せず、GitHub Pages ではヘッダを設定できないため適用していません。外部サイトからの iframe 埋め込みを厳密に防ぐ必要が生じた場合は、ヘッダを設定できるホスティングへの移行が必要です。
