# ナディーショーダナ（片鼻呼吸法）

ナディーショーダナを視覚的にガイドする PWA です。スマホのホーム画面に追加すると、オフラインでも単体アプリとして起動します。

## 画面の読み方

セッション画面は 3 本のバーが ∩ 字に並びます。

- **左右の縦バー** … 吸う / 吐く。常に上端を固定して高さが増減します。**減る＝吸う、増える＝吐く**
- **上辺の横バー** … 止める。息が入ってきた側から減っていきます

1 ラウンドは 6 フェーズです。

1. 左から吸う
2. 止める（両鼻）
3. 右から吐く
4. 右から吸う
5. 止める（両鼻）
6. 左から吐く

バーの分割数は秒数と一致します（止める 8 秒なら 8 分割）。色の境界はマス内を連続的に動き、1 秒ごとに目盛り線を通過します。1 マスが細かくなりすぎる場合のみ、目盛りなしの連続バーに切り替わります。

## プリセット

| プリセット | 吸う / 止める / 吐く | 1ラウンド | 初期ラウンド数 | 所要時間 |
| --- | --- | --- | --- | --- |
| 4-8-8 | 4 / 8 / 8 秒 | 40 秒 | 8 | 約 5 分 20 秒 |
| 6-12-12 | 6 / 12 / 12 秒 | 60 秒 | 5 | 約 5 分 |
| 4-16-8 | 4 / 16 / 8 秒 | 56 秒 | 5 | 約 4 分 40 秒 |
| カスタム | 自由 | — | 3〜20 | — |

ラウンド数はプリセットごとに記憶されます。

## 設定

### 表示設定

| 項目 | 選べるもの |
| --- | --- |
| 言語 | 日本語 / English |
| テーマ | ダーク / ライト |
| 文字の大きさ | 小 / 中 / 大 |
| バーの太さ | 細い / 普通 / 太い |

初回起動時はこの 4 項目を選ぶ画面から始まります（言語は端末の設定から推定した値が初期選択になります）。あとから「設定 → 表示設定」でいつでも変更できます。

### 通知設定

- 音（チャイム）／秒ごとのティック
- バイブレーション
- 音声ガイド（読み上げ・言語に追従）
- 画面を消さない（Wake Lock）

実施記録と連続日数は端末内（localStorage）にのみ保存され、外部には送信されません。

## カラー方針

2 テーマで同じ意味づけを保ちます。

| 色 | 意味 |
| --- | --- |
| ティール | 操作できる / 今アクティブ（開始ボタン、選択中、ON のトグル、主ボタン） |
| オレンジ | 継続記録（ストリーク） |
| ニュートラル | 上記以外すべて |
| ティール / バイオレット / オレンジ | 呼吸フェーズ（吸う / 止める / 吐く）。呼吸ビジュアル内部でのみ使用 |

ライトテーマはダークと同じ色相のまま明度だけを落としています。淡い色は白地で沈むためで、文字と背景の組み合わせはすべて WCAG AA（小さい文字 4.5:1）を満たす値を実測で選定しています。

なお完了画面のチェックマークだけは、押せない要素でありながら達成感の演出を優先してティールを使っています。これは意図的な唯一の例外です。

## 動作環境

PWA としての機能（ホーム画面への追加、オフライン起動、画面ロック抑止）は **HTTPS 配信時のみ** 有効です。
